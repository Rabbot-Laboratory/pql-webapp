# IMU適応歩行（実機導入ガイド）

## 実装範囲

シミュレーションで使用した考え方を、8軸の実機目標値を生成する
`compute_adaptive_walking_targets()` として独立させた。接地センサは使用せず、次の2種類の適応を25 Hzで同時に行う。

1. 各アクチュエータの目標値と現在位置の追従誤差から、軸ごとの位相進みをオンライン更新する。
2. IMUのRoll/Pitchと角速度から姿勢補正を生成し、残留する傾きをRoll/Pitchトリムとして徐々に学習する。

この関数はシリアル通信やWeb APIから独立している。そのため、実機ログを入力したオフライン再生テストと、実機制御で同じ計算を利用できる。

## WebGUIからの操作

1. Front/BackのESP32とBMX055を接続し、IMUの水平・ジャイロゼロ校正を済ませる。
2. 通常の「姿勢安定化」はOFFにする。適応歩行側がIMU補正を内蔵しており、同時には有効化できない。
3. WebGUIの「Motion」画面にある「IMU適応歩行」を開く。
4. ロボットを支持治具で保持し、周囲の安全、非常停止手段、空気遮断手段を確認してチェックを入れる。
5. 「押している間だけ前進」を押し続ける。離す、画面外へポインタを動かす、タブを切り替える、または通信が切れると目標更新を停止する。

既定ではMuJoCoで調整した `Motion/Fixed Motion/rabbit_bound.csv` を使う。1周期は1.8秒、全軸の機械レンジは65%以内、後膝は約0.30 rad相当に制限し、開始後2秒で0%から100%へ滑らかに上げる。ボタンは約150 msごとに継続要求を送り、サーバーは450 ms更新されなければ自動停止する。

## 自動停止と注意点

次の場合は新しい歩行目標の送信を停止し、最後に送信した姿勢を保持する。

- IMUデータがない、無効、または0.2秒より古い
- いずれかのアクチュエータテレメトリが0.5秒より古い
- RollまたはPitchが12度を超える
- Front/Back ESP32の接続が切れる、または送信に失敗する
- ボタンの継続要求が450 ms途切れる
- 通常の姿勢安定化が有効になる

目標更新の停止は減圧や電源遮断ではない。実機試験では必ず、WebGUIとは独立した物理的な空気遮断・非常停止手段を手の届く位置に用意する。

実機モードでは、歩行開始前に8軸すべてのテレメトリ受信を要求する。手動目標、CSV再生、通常の姿勢安定化とは排他的に動作する。

## 初回の実機試験

この実装はデモデバイスと自動テストでは確認済みだが、実機では未検証である。最初は次の順序で確認する。

1. 脚を地面から離した支持状態、低圧、20%振幅のまま、0.5秒未満の短い押下を行う。
2. 各軸の目標方向と実際の伸縮方向、IMUを傾けたときの補正方向を確認する。
3. ログの追従誤差、学習位相、Roll/Pitchトリム、停止理由を確認する。
4. 問題がなければ短時間の接地試験へ進み、振幅と速度を少しずつ上げる。

初回ログを基に調整する主な設定値は以下である。環境変数では設定名を大文字にして `HIGHEND_` を付ける。

| 設定 | 既定値 | 目的 |
|---|---:|---|
| `adaptive_walk_motion_scale` | 1.00 | rabbit_bound.csvの最終振幅倍率 |
| `adaptive_walk_motion_ramp_sec` | 2.0 | 0%から最終振幅までの時間 |
| `adaptive_walk_max_target_rate` | 1200 | 1秒あたりの最大目標変化量 |
| `adaptive_walk_learning_rate` | 0.08 | 軸別位相学習の速さ |
| `adaptive_walk_feedback_gain` | 0.10 | 追従誤差の瞬時補正 |
| `adaptive_walk_attitude_kp` | 2.0 | Roll/Pitch比例補正 |
| `adaptive_walk_attitude_kd` | 0.25 | 角速度による減衰 |
| `adaptive_walk_trim_rate` | 0.20 | 姿勢トリム学習の速さ |
| `adaptive_walk_max_tilt_deg` | 12 | 自動停止する最大傾斜 |
| `adaptive_walk_max_actuator_staleness_sec` | 0.5 | 軸テレメトリ停止の判定時間 |

接地センサを使わないため、滑りや足先の接地失敗を直接検出する制御にはなっていない。実機ログ取得後は、各シリンダの伸長・収縮速度、むだ時間、IMU軸符号、適正な姿勢ゲインを優先して微調整する。
