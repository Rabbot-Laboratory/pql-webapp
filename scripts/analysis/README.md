# 歩行ログ解析スクリプト

**Pi上で実行する**(`~/pql-webapp/Logs/experiments/<run>/` を直接読む)。
`pi_fetch_logs.py` でローカルへ回収した場合は各スクリプトの `ROOT`/`BASE` を
書き換えること。

| スクリプト | 用途 |
|---|---|
| `cross_analysis.py <run> [<run>...]` | **主力**。全走行区間を横断し、軸の実移動量・姿勢コヒーレンス(歩行周期との同期度)・接地デューティ・端張り付き率で歩容を比較 |
| `compare_segments.py <run> name:start:end ...` | 1つの記録内で区間ごとに軸別追従を比較 |
| `analyze_run.py <run>` | 1記録のイベント時系列 + 歩行中の軸別指令/実測 |
| `noise_check.py <run>` | 位置センサのスパイクノイズ(静止時 vs 歩行時) |

## 評価の見方(2026-08-30の知見)

- **Rollコヒーレンス**: 0.8前後 = 歩行周期に同期した規則正しい体重移動。
  0.2以下は「ただ振動しているだけ」。**距離より信頼できる指標**。
- **後足接地率**: 20%超が目安(前足センサは現在0%固定=要配線確認)。
- **端張り付き率(end%)**: 0%に近いほど良い。高い軸は仕事をしていない。
- **移動量(travel/s)**: 多ければ良いわけではない。trot_fast8は最小だが最良だった。
